总览

操作流程

  1. 打开 API 池，按每行 api_id:api_hash 批量写入。一号只能用一条 API。
  2. 打开 IP 线路池，填线路名（如 us-01），按每行 ip:端口:用户:密码 批量写入。
  3. 打开 镜像账号，填写水军显示名/手机号，下拉选择空闲 IP，点「保存并自动分配 API」。
  4. 总览核对：账号数、API 空闲/总量、IP 空闲/总量、已配对是否对得上。
  5. 监控与衍射、克隆绑定、关键词、群组、消息、任务、事件：界面已在，需 Telegram worker 接入后才有真实收发。

注意事项

  • 当前面板和 /api 尚未加登录，不要把地址发给外人，不要在公共电脑打开。
  • API Hash、代理密码存在服务器数据库中，批量粘贴后不要再发到群或截图外传。
  • 必须先有空闲 API 才能加号；池空了会提示失败，不要重复点保存。
  • 一条 IP、一条 API 同时只允许绑一个账号。删号后才会回到空闲池。
  • 8010 后端进程不能停。若页面又出现 502，先在服务器把 python3 /opt/tgchat-live/server.py 拉起来。
  • 请用 https://tgchat.pw 访问。配完后强制刷新（Ctrl+F5）再看池数据。
  • 演示数字不会再出现在总览；总览 0 表示库是空的，不是故障。
